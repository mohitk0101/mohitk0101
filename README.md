### 🔹 CampusFind — Full-Stack Web Application

A campus-focused lost-and-found platform built to help students report lost items and connect with people who find them.

**Highlights:**
- User authentication and role-based access
- Lost and found item listings
- Image uploads and item moderation
- Real-time chat functionality
- Notifications and MongoDB integration

**Tech Stack:** React, Node.js, Express.js, MongoDB, Socket.IO, JWT, Cloudinary

🔗 [Live Demo](https://campus-find-livid.vercel.app/)
